# SkillCraft Technology Internship - Task 03

## Global Happiness Index Interactive Dashboard

### Objective
Analyze world happiness trends across top countries, geographic regions, and economic indicators (Economy / GDP) using Tableau Public.

### Key Insights
- **Top Performers**: Norway, Denmark, Iceland, Switzerland, and Finland top the world in average happiness score.
- **Regional Breakdown**: Visual analysis comparing total/average happiness across regions like Asia-Pacific, Africa, Latin America, and Western Europe.
- **Economic Correlation**: A clear, positive correlation exists between higher Economic (GDP) scores and overall Happiness Score.

### Visualizations Included
1. **Top Happiest Countries**: Bar chart displaying top-ranked nations.
2. **Happiness by Region**: Categorical breakdown across geographic regions.
3. **GDP vs Happiness**: Scatter plot showing the impact of economic status on happiness scores.
